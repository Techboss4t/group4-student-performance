
STUDENT PERFORMANCE PREDICTION SYSTEM (UPDATED STYLED VERSION)

FILES:
- model.py   -> trains the AI model
- app.py     -> runs the Flask web app
- templates/index.html -> styled HTML frontend

HOW TO RUN (PowerShell):

1. Install dependencies:
   pip install pandas scikit-learn flask

2. Train the model:
   python model.py

3. Run the app:
   python app.py

4. Open browser:
   http://127.0.0.1:5000
